## Projects

### Employee Salary Prediction

Applied machine learning techniques to the Adult Census Income dataset to classify whether annual income is above or below $50K.

**Highlights:**
- Handled unknown categorical values and encoded features using Label Encoding.
- Applied Min-Max Scaling and an 80/20 stratified train-test split.
- Compared KNN, Logistic Regression, and MLP classifiers.
- KNN — **82.69% accuracy**
- Logistic Regression — **82.73% accuracy**
- MLP — **85.18% accuracy** (highest among the tested models)

**Technologies:** Python, Pandas, Scikit-learn, MLP, KNN

**Repository:** [Employee Salary Prediction](https://github.com/sivakumar9867/Employee-Salary-Prediction)
