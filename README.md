# Siva Kumar — Developer Portfolio

Version 2: polished, responsive, placement-focused portfolio.

## Open locally
Open `index.html` in a browser. No build tools are required.

## Included
- Responsive developer-style UI
- Animated reveal effects
- Experience timeline
- Project cards
- Skills
- Individual certificate preview cards using the supplied original certificates
- Resume link
- GitHub / LinkedIn / email links
- Mobile layout

## Notes
Each internship certificate has its own preview image and certificate document. Individual project repository links were not provided, so project buttons currently open the GitHub profile rather than inventing repository URLs.
